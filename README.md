
# MyPetsFriends ERP

## Descripción
Sistema ERP para la gestión integral de la clínica veterinaria MyPetsFriends.

El proyecto busca centralizar la administración de propietarios, mascotas, citas, consultas, inventario, ventas y facturación.

## Tecnologías utilizadas
- Odoo Community 20.0
- PostgreSQL
- Docker
- Docker Compose
- Git y GitHub

## Objetivo
Implementar un sistema portable, fácil de reinstalar y que no dependa de licencias comerciales.
